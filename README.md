# Inventfy

Sistema de gerenciamento de almoxarifado para o SENAI, voltado às oficinas dos eixos de metalmecânica e eletroeletrônica, com expansão futura prevista para os eixos de vestuário e tecnologia da informação.

## Sobre o projeto

Auxilia alunos, docentes e equipe técnico-pedagógica a controlar o gerenciamento de componentes, peças e ferramentas — incluindo entrada, saída e pedidos de empréstimo.

Hoje o controle é feito por planilha de papel (metalmecânica) ou não existe (eletroeletrônica), dificultando saber o que há em estoque, em que quantidade, quem usou e se foi devolvido.

## Objetivos

1. Controlar entrada/saída e quantidade de peças, componentes e ferramentas.
2. Indicar usuário atual e histórico de uso.
3. Solicitar e aprovar empréstimos para discentes e outros ambientes.
4. Padronizar o uso do sistema entre todos os envolvidos.
5. Auxiliar pedidos de compra.
